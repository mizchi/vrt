# 課題: 注文の状態遷移（日本語）

EC サイトの注文がたどる状態を、状態機械のアニメーションとして `scene.json`
に書いてください。読者は日本語話者のカスタマーサポート担当で、「この注文は
今どの状態で、次に何が起きうるか」を図で理解したい人です。

状態（**ラベルは日本語**、id は自由）: 受付済み、支払い待ち、支払い完了、
出荷準備中、出荷済み、配達完了、キャンセル済み（最終状態）、返金済み
（最終状態）。

イベント（遷移のラベル、日本語）:
- 受付済み —注文確定→ 支払い待ち
- 支払い待ち —入金確認→ 支払い完了
- 支払い待ち —期限切れ→ キャンセル済み
- 支払い完了 —ピッキング開始→ 出荷準備中
- 出荷準備中 —発送→ 出荷済み
- 出荷済み —受領→ 配達完了
- 支払い完了 —キャンセル要求→ 返金済み
- 出荷準備中 —キャンセル要求→ 返金済み

遷移には `note` で何が送られるかを書いてください（例:「/ 確認メール送信」）。
まず通常の経路（注文確定、入金確認、ピッキング開始、発送、受領）をトレースで
見せ、そのあと `goto` で支払い完了に戻ってキャンセル要求の経路も再生してください。
キャプションは日本語で、一文ずつ。

提出物: `scene.json`、`states.svg`（`vlmkit-anim still --step N` で全状態が
見える一枚）、`log.md`。

成功条件: `vlmkit-anim check scene.json` が ✗ なしで 0 で終わる（描かれたが
トレースが通らない遷移についての ⚠ は、log に理由があれば可）。
`vlmkit-anim layout scene.json` が問題なしと報告する。

`log.md` に必ず書くこと: 手で書いた座標・色・キャンバスサイズがあれば全部と
その理由。日本語ラベルで困ったこと（状態の円にラベルが収まるか、遷移ラベルの
重なり、ガイドに書いてなかったこと）。図に入れたかったが表現できなかったこと。
